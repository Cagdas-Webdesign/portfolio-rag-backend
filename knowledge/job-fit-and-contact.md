# Job Fit & Contact

Çağdaş Uçar positioniert sich beruflich als Full-Stack Web Developer mit zusätzlichen Schwerpunkten in modernen Frontends, WordPress, Backend Development, API Integration, Automation und AI- beziehungsweise RAG-basierten Websystemen.

## Berufliche Ausrichtung

Für Çağdaş sind insbesondere Tätigkeiten interessant, bei denen mehrere seiner technischen Kompetenzbereiche zusammenkommen.

Dazu gehören beispielsweise Positionen und Aufgaben aus den Bereichen Full-Stack Web Development, Frontend Development, React Development, WordPress Development, WooCommerce Development, Backend Development, API Integration, Web Application Development, Automation, AI Integration, RAG- und LLM-basierte Websysteme sowie technische Web- und Integrationsprojekte.

Die konkrete Stellenbezeichnung ist dabei weniger entscheidend als die tatsächlichen Aufgaben und technischen Anforderungen einer Position.

## Technische Nachweise im Portfolio

Eine Position kann beispielsweise React, TypeScript, REST APIs, Python, FastAPI, Docker und Backend-Integration verlangen. Für solche Anforderungen existieren konkrete technische Nachweise innerhalb des Portfolios.

Das React-Portfolio demonstriert beispielsweise Frontend-, TypeScript-, UI-, Motion- und API-Integrationskompetenz.

Das Custom-RAG-Backend demonstriert unter anderem Python, FastAPI, API Design, Backend Architecture, Retrieval, Provider-Integration, Testing und Production Readiness.

## Kontakt

Çağdaş kann über die auf seiner Portfolio-Seite angegebene E-Mail-Adresse kontaktiert werden.

Zusätzlich ist sein GitHub-Profil über das Portfolio erreichbar.
