# Full-Stack Web Development

Çağdaş Uçar positioniert sich als Full-Stack Web Developer.

Sein Schwerpunkt liegt darauf, moderne Weboberflächen nicht isoliert vom technischen Unterbau zu betrachten. Er beschäftigt sich mit Frontend, Backend, APIs, Datenhaltung und der Kommunikation zwischen diesen Komponenten.

## Frontend Development

Çağdaş arbeitet im modernen Frontend Development mit React und nutzt React als zentrale Technologie für komponentenbasierte Webanwendungen.

Sein Frontend-Stack umfasst unter anderem:

- React – komponentenbasierte Frontend-Entwicklung
- TypeScript – erweitert JavaScript um statische Typisierung und unterstützt robusteren und besser wartbaren Frontend-Code
- JavaScript – grundlegende Programmlogik und Interaktionen im Web
- HTML – semantische Struktur
- CSS – Styling, Layout und Responsive Design
- Framer Motion – React-basierte Animationen, Transitions und UI-Interaktionen
- GSAP – komplexere, timeline- und scrollbasierte Webanimationen
- Figma – UI/UX-Konzeption und Design

TypeScript baut auf JavaScript auf und erweitert die Sprache unter anderem um ein statisches Typsystem. Dadurch können viele Fehler bereits während der Entwicklung erkannt und größere React-Anwendungen strukturierter entwickelt werden.

Mit React strukturiert Çağdaş Benutzeroberflächen in wiederverwendbare Komponenten und trennt unterschiedliche Verantwortlichkeiten innerhalb des Frontends.

Dazu gehören Component Architecture, Props, State, Event Handling, Rendering, Responsive Layouts, API-Kommunikation und dynamische Benutzeroberflächen.

## UI Development und Figma

Frontend Development und UI Design gehören für Çağdaş eng zusammen.

Er arbeitet mit Figma für die Konzeption und Gestaltung von Benutzeroberflächen.

Dazu gehören Wireframes und Layout-Konzeption, Responsive Designs, Komponenten, Design-System-Denken, Typografie, Spacing, visuelle Hierarchie, Navigation, Interaktionskonzepte, Desktop- und Mobile-Layouts sowie der Übergang vom Design zur technischen Umsetzung.

## Motion und Web Animation

Çağdaş setzt Framer Motion und GSAP als Bestandteil moderner Frontend-Entwicklung ein.

Animationen werden dabei nicht isoliert als visueller Effekt betrachtet, sondern in die Komponentenstruktur, Nutzerführung und Interaktionslogik der Anwendung integriert.

## Backend Development

Çağdaş arbeitet im Backend unter anderem mit:

- Python – zentrale Sprache für Backend- und RAG-Logik
- FastAPI – HTTP/API-Schicht für moderne Python-Backends
- REST APIs – Kommunikation zwischen Frontend, Backend und externen Diensten
- Cloudflare Workers – leichte serverseitige und Edge-basierte Logik sowie sichere API-Proxies
- Cloudflare Vectorize – Vector Store für semantisches Retrieval
- Cloudflare Workers AI – LLM-Provider für die Textgenerierung im RAG-Kontext
- Mistral – Embedding-Provider im AI- und RAG-Kontext
- Docker – reproduzierbare Laufzeit- und Entwicklungsumgebungen
- PostgreSQL, MySQL, MongoDB und Supabase – Datenhaltung je nach Anwendungsfall
- Webhooks – ereignisbasierte Kommunikation zwischen Systemen

In seinem Custom-RAG-Backend kommen zusätzlich Architekturbausteine wie Knowledge Ingestion, Validation, Chunking, Embeddings, Vector Indexing, Retrieval, Context Building, Prompt Construction, LLM Generation, Citation Validation und Grounded Responses zum Einsatz.

Dazu kommen Konzepte wie Ports & Adapters, Composition Root, Provider-Abstraktion, Error Handling, strict typing, Evaluation, Security Boundaries und automatisierte Tests.

## Frontend und Backend verbinden

Ein wichtiger Bestandteil seines Full-Stack-Verständnisses ist der Contract zwischen Frontend und Backend.

Das Frontend und Backend sind getrennte Komponenten, die über definierte Schnittstellen miteinander kommunizieren.

Beispielsweise:

Nutzerinteraktion  
→ React Frontend  
→ HTTP Request  
→ REST Endpoint  
→ Backend-Verarbeitung  
→ Response  
→ React Frontend  
→ Darstellung für den Nutzer

Ein falscher Endpoint, ein nicht passendes Request-Format oder ein nicht eingehaltenes Response-Schema kann diese Kommunikation unterbrechen.

Deshalb betrachtet Çağdaş nicht nur beide Seiten einzeln, sondern auch die Schnittstelle zwischen ihnen.

## API Integration

API-Integration gehört zu seinem Full-Stack-Bereich.

Dazu gehören REST APIs, REST Endpoints, HTTP Requests, Request und Response, JSON, Webhooks, externe Services, Frontend-to-Backend-Kommunikation, Backend-to-Provider-Kommunikation und Fehlerbehandlung an Systemgrenzen.

Eine API versteht Çağdaş als definierte Schnittstelle, über die getrennte Systeme miteinander kommunizieren können.

## PHP und Web Development

PHP gehört ebenfalls zu seinem technischen Hintergrund und wird insbesondere im WordPress-Kontext eingesetzt.

Dazu gehören beispielsweise serverseitige WordPress-Funktionen, individuelle Erweiterungen, Plugin Development, Hooks und die Verbindung zwischen Backend-Logik und Frontend-Ausgabe.

## Java

Çağdaş verfügt außerdem über Erfahrung mit Java.

Java gehört zu seinem Programmierhintergrund, ist aktuell jedoch nicht der zentrale Technologie-Stack seiner Portfolio-Projekte.

Seine aktuelle Positionierung im Webbereich liegt stärker auf Technologien wie React, TypeScript, JavaScript, PHP sowie Python und FastAPI.

## Full-Stack-Verständnis

Full-Stack bedeutet in diesem Profil nicht, jede existierende Frontend-, Backend- oder Cloud-Technologie zu beherrschen.

Es bedeutet, eine Webanwendung über mehrere technische Ebenen hinweg verstehen und entwickeln zu können:

User Interface → Frontend → API → Backend → Daten oder Services → Response.

Çağdaş' Schwerpunkt liegt dabei besonders auf der Verbindung dieser Ebenen zu funktionierenden, erweiterbaren Websystemen.
